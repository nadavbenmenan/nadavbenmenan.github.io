חיבור למאגר שלך

האפליקציה שומרת את ההגשות בקובץ הגשות.json שבמאגר הפרטי nadavbenmenan/cv. אין כאן שרת ואין שום צד שלישי: הדפדפן מדבר ישירות מול גיטהאב. צריך אסימון אישי פעם אחת במכשיר הזה.
  1. פתח את יצירת אסימון מדויק בחשבון nadavbenmenan.
  2. ב-Repository access בחר Only select repositories ואז cv.
  3. ב-Permissions פתח Contents והעבר ל-Read and write.
  4. צור, העתק את האסימון והדבק כאן.
האסימון נשמר רק בדפדפן הזה ולא נשלח לשום מקום חוץ מגיטהאב. אפשר לבטל אותו בכל רגע בהגדרות החשבון, וההגשות לא ייפגעו.
